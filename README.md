# Portfolio Interactif - Swann Accajou

Ce projet est un CV interactif et dynamique développé avec **Streamlit**. Il présente le parcours professionnel, les compétences techniques et la formation de Swann Accajou.

## 🚀 Fonctionnalités
- **Navigation par onglets** : Expériences, Formation, et Langues/Intérêts.
- **Barre latérale interactive** : Accès rapide aux contacts et expertises techniques.
- **Design personnalisé** : Utilisation de CSS pour une interface professionnelle aux couleurs de l'EFREI/AGL.
